# 员工多岗位 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 员工 `role: string` → `roles: string[]` 多岗位；调度 `pkg.role ∈ emp.roles`；注入按任务岗位过滤（无任务岗位/点名岗位不在集合 → 全岗位并集兜底）；前端岗位多选 + tags 展示。

**Architecture:** 存储层 roles 数组 + 旧单值兼容包装（读路径归一）；调度与注入的「岗位」消费点各自扩展——调度集合匹配（一行），注入在装配层 skillsFor 加第二参 taskRole 完成过滤（plan-runner/worker 零改动）；handlers GET 视图与前端类型同步 roles。

**Tech Stack:** TypeScript / Node（pnpm workspace）、vitest、Vue3 + element-plus + Tailwind v4。

## Global Constraints

- 全程简体中文注释与文案；conventional commits 中文描述
- 兼容：旧 `employees.json`（单值 `role`）读入包装为 `roles: [role]`，不迁移文件；旧 `skills`/`skillCategories` 继续忽略
- `EmployeeProfile`（runtime 类型）零改动——`profileOf` 取 `roles[0]` 作主岗填充
- runtime 包零改动；plan-runner.ts / worker.ts / skill-injection.ts 零改动
- 员工至少挂一个岗位（roles 非空），防孤儿档案
- 测试：`pnpm --filter console-api test`、`pnpm --filter console test`；收官 `pnpm -r typecheck` 零错误
- 每任务一次 git commit；不改 `packages/console-api/data/` 运行数据

export function normalizeEmployeeInput(rec: EmployeeRecord): EmployeeRecord {
  // 多岗位归一（2026-09-07）：旧单值 role 包装为 roles（兼容旧前端/旧文件提交）
  const withRoles = (() => {
    const r = rec as EmployeeRecord & { role?: string };
    if (Array.isArray(rec.roles)) return rec;
    if (typeof r.role === 'string') return { ...rec, roles: r.role.trim() ? [r.role] : [] };
    return { ...rec, roles: [] };
  })();
  const s: unknown = (withRoles as { supervision?: unknown }).supervision;
  if (typeof s === 'string') {
    return { ...withRoles, supervision: { level: s as 'shadow' | 'assisted' | 'trusted' } };
  }
  return withRoles;
}
