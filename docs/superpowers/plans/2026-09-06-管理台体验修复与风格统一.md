# 管理台体验修复与风格统一 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 修复下钻页返回缺失、列表页统一任务中心风格（上检索/按钮 + 下表格）、全站 size 归默认、修复消息中心 400。

**Architecture:** 纯前端为主（apps/console）+ 一处后端依赖注入修复（console-api server.ts）。风格标杆 = TaskCenter.vue（default 尺寸、工具条 mb-4、el-table）。

**Tech Stack:** Vue 3 + Element Plus + Tailwind v4（apps/console）；node:http handlers（packages/console-api）。

## Global Constraints

- size 一律默认：删除全部 `size="small"`；`el-drawer size="400px"`（宽度属性）保留；`el-form size="default"` 显式值删除。
- 列表页标准结构：顶部工具条（左检索/筛选 + 右主按钮 `class="ml-auto"`）`class="mb-4"` + 下 el-table；布局/间距用 Tailwind，EP 控件不覆写。
- spec 偏差裁定：PendingCheck 仅 `{ taskId, item, result }`，CheckReview 表格列按真实字段 = 任务ID/检查项/申报结果/操作（spec 中「员工/盯梢级/状态/时间」列无数据源，不为列表页扩后端）。
- 组件不得新增 scoped style（:deep ≤10 行/文件）；不改 script 业务逻辑（轮询/API 调用），只改展示层与新增检索过滤。
- 测试不监听端口；命令：`pnpm --filter console exec vitest run`、`pnpm --filter console-api exec vitest run`、`vue-tsc --noEmit`（apps/console 下）。
- 提交：中文 conventional commits，末尾 `Co-Authored-By: Claude Code <noreply@anthropic.com>`。
