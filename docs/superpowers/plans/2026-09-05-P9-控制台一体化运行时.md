## 前置环节 A: hash 链快照归档（审计存证成立的前提）

**问题**：verifyChain 是全链重算——能改库的人也能重算整条链，verify 照样绿。快照把历史链头 hash 写到**独立文件**，校验时"当前链"对"历史快照"验，篡改者拿不到快照写权限才成立。

**Files:**
- Modify: `stores/types.ts`——`EventStore.snapshotHead?(): Promise<{ id: string; hash: string }>`
- Modify: `file-event-store.ts` / `sqlite-event-store.ts`——append 当前链头到独立快照文件（file: `<dir>/audit-heads.jsonl`；sqlite: `<dbPath>.heads.jsonl`）
- Modify: `hash-chain.ts` verifyIntegrity 语义——快照点的 hash 必须与当前链一致
- Test: 契约用例：append N 条 → 快照 → 再 append → 篡改快照点之前的事件 → verify 报 brokenAt 且快照校验失败
