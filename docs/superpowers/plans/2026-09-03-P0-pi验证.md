# P0 · pi 扩展点验证计划（Spike）

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 用最小 spike 逐项验证 pi agent harness 的 5 个扩展点 + vLLM 连通冒烟 + beforeToolCall 拦截可行性，产出 GO / NO-GO 结论（GO → P1 改写为 pi 封装计划；NO-GO → 回退已写好的自研 P1 计划）。

**Architecture:** 在 monorepo 下建独立 spike 包 `packages/spike-pi/`，直接依赖 `@earendil-works/pi-agent-core` 与 `@earendil-works/pi-ai`。全部逻辑验证用 pi 的 Faux Provider（假模型，离线可测）；唯一真模型项是 vLLM 连通冒烟（连不上则标记 skip，不影响结论）。每个 spike 一个独立测试文件，通过/失败标准明确，最后汇成验证清单写入 `packages/spike-pi/VERDICT.md`。

**Tech Stack:** TypeScript 5.5+ / vitest / `@earendil-works/pi-agent-core`、`@earendil-works/pi-ai`（版本以安装时最新为准，安装后锁定精确版本）。

## Global Constraints

- 全程离线可测：逻辑 spike 只用 Faux Provider，禁止依赖公网；vLLM 冒烟地址从环境变量 `PI_SPIKE_VLLM_URL` 读取，未设置或不可达自动 skip
- spike 代码不进生产依赖，仅供验证；结论（VERDICT.md）才是交付物
- 依赖安装遵守行内供应链准入：安装后记录精确版本号到 VERDICT.md，供后续安全审计
- 每个 spike 独立成测试文件，独立可运行：`pnpm --filter @ddw/spike-pi test -- <file>`

/** 我们 spec 定义的 AgentEvent（从 @ddw/runtime 复制最小版，避免 spike 依赖 runtime 包） */
type AgentEventType = 'thinking' | 'tool_call' | 'report';
interface AgentEvent {
  id: string; ts: number; taskId: string; employeeId: string;
  type: AgentEventType; summary: string; payload?: unknown;
}

/**
 * 验证点③：pi 事件 → AgentEvent 映射。
 * pi 事件流（README 确认的序列）：
 *   agent_start, turn_start,
 *   message_start, message_update(含 assistantMessageEvent delta), message_end,
 *   tool_execution_start, tool_execution_update, tool_execution_end,
 *   turn_end, agent_end
 */
function piEventToAgentEvent(piEvent: any, taskId: string, employeeId: string): AgentEvent | null {
  switch (piEvent.type) {
    case 'message_end':
      if (piEvent.message?.role === 'assistant' && piEvent.message.content) {
        return {
          id: randomUUID(), ts: Date.now(), taskId, employeeId,
          type: 'thinking',
          summary: String(piEvent.message.content).slice(0, 200),
          payload: { content: piEvent.message.content },
        };
      }
      return null;
    case 'tool_execution_end':
      return {
        id: randomUUID(), ts: Date.now(), taskId, employeeId,
        type: 'tool_call',
        summary: piEvent.toolName,
        payload: { toolCallId: piEvent.toolCallId, result: piEvent.result },
      };
    default:
      return null; // turn_start/end 等生命周期事件不进直播流
  }
}
