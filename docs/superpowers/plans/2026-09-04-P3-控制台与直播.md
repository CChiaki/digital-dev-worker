# P3 · 控制台任务中心 + 事件直播 + 审计台账 v1 实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 交付轻量控制台 v1：任务中心（固化任务包/任务池/接单状态）、员工中心（AgentEvent 实时直播）、审计中心（全操作台账 v1）。前后端分离：`@ddw/console-api`（Node HTTP，零框架）+ `apps/console`（Vue3）。

**Architecture:**
- **console-api**：数据层（TaskStore 任务池 + EventStore 事件流读取）+ HTTP handler 层。**零运行时依赖**（node:http + 手写极简路由）。handler 设计为 `(req) => Promise<res>` 纯函数——测试直接调 handler，**不监听端口**（用户约束：未经命令不启动服务/不占端口）。
- **apps/console**：Vue3 + Vite 骨架，四个视图：任务池 / 任务详情 / 员工直播 / 审计台账。组件测试用 @vue/test-utils + jsdom（不启动 dev server，不执行 build）。
- 事件数据源 = P1 的 `EventBus` + `JsonlSink` 落盘文件；直播用轮询（v1，SSE 留 P5）。
- 接单闭环（同进程演示）：固化任务包 → claim → 同进程调 `EmployeeRuntime.runTaskPackage` → 事件落盘 → 直播可见。真实进程隔离/容器调度留 P4。

**Tech Stack:** TypeScript / vitest / Vue3 + Vite（仅前端）。console-api 零依赖。

## Global Constraints

- 沿用 P1/P2 全部约束（离线 / ESM / TDD / Tool 契约）
- **测试全程不监听端口、不执行 build/dev 命令**（遵守用户约束）；API 以 handler 纯函数测试

**Interfaces:**
- `interface TaskRecord { pkg: TaskPackage; status: 'pending' | 'claimed' | 'running' | 'done' | 'failed'; claimedBy?: string; claimedAt?: number; result?: EmployeeOutcome }`
- `class TaskStore { constructor(dir: string); add(pkg: TaskPackage): Promise<TaskRecord>; list(): Promise<TaskRecord[]>; get(taskId): Promise<TaskRecord | null>; claim(taskId, employeeId): Promise<TaskRecord>（pending→claimed，非 pending 抛错） ; finish(taskId, outcome, ok: boolean): Promise<TaskRecord> }`——JSON 落盘 `<dir>/tasks/<taskId>.json`
- `class EventStore { constructor(eventsDir: string); append(event: AgentEvent)（复用 JsonlSink 语义）; list(filter?: { taskId?, employeeId?, type?, since? }): Promise<AgentEvent[]> }`——读 `<eventsDir>/*.jsonl` 全量，半行跳过，按 ts 升序

### 实现校准点（对计划的偏离/发现）

1. **EventBus 并发乱序（重要修复）**：`emit` 的 sink 写入原为并发 append，Faux 快速连发工具事件时 JSONL 落盘顺序与 emit 调用顺序不一致 → runtime `bus.ts` 增加写队列（`queue.then(write)`），写入顺序全局保序，P1 30 用例零回归。
2. **测试目录隔离**：EventStore 递归读目录下所有 `*.jsonl`，session 落盘文件混入会被当事件读 → e2e 中 session 根与 console dataDir 分离（生产上本就是不同目录）。
3. **`since` 语义**：`ts >= since`（非严格大于）——增量轮询重拉同 ts 事件幂等无害，避免同毫秒漏事件。
4. **claimId()**：v1 简化为 localStorage 可改的操作者身份（默认 emp-01）；真实"员工注册/鉴权"留后续阶段。
