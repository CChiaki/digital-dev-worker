# 模型网关双协议兼容（OpenAI / Anthropic）实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** ModelGateway 支持按路由配置协议（`openai-completions` | `anthropic-messages`），用户智谱 Coding Plan 的 Anthropic 端点（`/api/anthropic` + glm-5.3-flash）可直接使用，老配置零回归。

**Architecture:** `ModelSpec` 加可选 `api` 字段；gateway 的 `toPiModel` 按 api 设模型协议与认证头（openai→Bearer，anthropic→x-api-key），`streamFnFor` 缺省流式函数按路由协议从 pi-ai 选对应 `streamSimple`。executor/调度器/worker 经 gateway 取 model 与 streamFn，`StreamFn` 本就协议无关，消费方零改动。

**Tech Stack:** TypeScript、`@earendil-works/pi-ai`（已有 `api/anthropic-messages` 适配器，子路径导出 `./api/*`）、vitest。

**Spec:** `docs/superpowers/specs/2026-09-05-模型网关双协议兼容-design.md`

## Global Constraints

- 缺省不写 `api` = 行为与现状完全一致（老配置零回归）
- 协议枚举仅两个值：`openai-completions`、`anthropic-messages`；配置非法值启动即失败、错误信息可读（带字段路径）
- 不做 URL 自动识别、不做第三种协议、不做 per-请求协议切换
- 测试在包目录跑（`cd packages/runtime && pnpm test`）；不执行启动/监听端口类命令
- 提交信息 conventional commits 中文，结尾 `Co-Authored-By: Claude Code <noreply@anthropic.com>`

`packages/runtime/src/model/gateway.ts` 全文改为：

```ts
import type { StreamFn } from '@earendil-works/pi-agent-core';
import type { Model } from '@earendil-works/pi-ai';
import { streamSimple as openaiStreamSimple } from '@earendil-works/pi-ai/api/openai-completions';
import { streamSimple as anthropicStreamSimple } from '@earendil-works/pi-ai/api/anthropic-messages';
import type { CallType, ModelApi, ModelSpec, RouteConfig } from '../types.js';

/** pi Model 的产品级默认值（行内模型按需覆盖） */
const DEFAULT_CONTEXT_WINDOW = 128_000;
const DEFAULT_MAX_TOKENS = 8_192;

/** 协议 → pi-ai 缺省流式适配器（streamFnFor 未显式注入时按路由协议选） */
const DEFAULT_STREAM: Record<ModelApi, StreamFn> = {
  'openai-completions': openaiStreamSimple as StreamFn,
  'anthropic-messages': anthropicStreamSimple as StreamFn,
};

function toPiModel(spec: ModelSpec): Model<ModelApi> {
  const api = spec.api ?? 'openai-completions';
  return {
    id: spec.model,
    name: spec.name,
    api,
    provider: 'ddw-custom',
    baseUrl: spec.baseUrl.replace(/\/$/, ''),
    // glm-5.3-flash 等推理模型走 Anthropic 端点会回思考块：标记 reasoning，
    // 避免流式解析把 thinking 当正文；OpenAI 私有集群维持 false
    reasoning: api === 'anthropic-messages',
    input: ['text'],
    cost: { input: 0, output: 0, cacheRead: 0, cacheWrite: 0 },
    contextWindow: DEFAULT_CONTEXT_WINDOW,
    maxTokens: DEFAULT_MAX_TOKENS,
    // openai → Bearer；anthropic → x-api-key（anthropic-version 由 SDK 默认补）
    headers:
      api === 'anthropic-messages'
        ? { 'x-api-key': spec.apiKey }
        : { Authorization: `Bearer ${spec.apiKey}` },
  };
}

export class ModelGateway {
  private readonly routes: Map<CallType, RouteConfig>;

  constructor(routes: RouteConfig[]) {
    this.routes = new Map(routes.map((r) => [r.callType, r]));
  }

  modelFor(callType: CallType): Model<ModelApi> {
    const route = this.routes.get(callType);
    if (!route) throw new Error(`未配置的调用类型: ${callType}`);
    return toPiModel(route.primary);
  }

  /**
   * 返回带 fallback 的 StreamFn：primary 流式失败时，用 fallback 模型重试同一轮。
   * stream 参数可注入 fake（测试）；缺省按路由协议选适配器（primary/fallback 各自独立，
   * 跨协议 fallback 可用）。
   */
  streamFnFor(
    callType: CallType,
    stream: StreamFn = DEFAULT_STREAM[this.routes.get(callType)?.primary.api ?? 'openai-completions'],
    fallbackStream?: StreamFn,
  ): StreamFn {
    const route = this.routes.get(callType);
    const fallbackSpec = route?.fallback;
    return async (model, context, options) => {
      try {
        return await stream(model, context, options);
      } catch (err) {
        if (!fallbackSpec) throw err;
        const fb = fallbackStream ?? DEFAULT_STREAM[fallbackSpec.api ?? 'openai-completions'];
        return await fb(toPiModel(fallbackSpec), context, options);
      }
    };
  }
}
```

```ts
  // 协议字段（可选）：缺省 openai-completions；anthropic-messages 走 Anthropic Messages API
  const apiOf = (v: unknown, field: string): void => {
    if (v === undefined) return;
    if (!['openai-completions', 'anthropic-messages'].includes(v as string)) {
      fail(`${field}.api`, `必须是 openai-completions/anthropic-messages 之一，得到 ${JSON.stringify(v)}`);
    }
  };
  apiOf(prim['api'], `${field}.primary`);
  const fb: unknown = raw['fallback'];
  if (fb !== undefined) {
    if (typeof fb !== 'object' || fb === null) fail(`${field}.fallback`, '必须是对象');
    const fbo = fb as Record<string, unknown>;
    for (const k of ['baseUrl', 'apiKey', 'model'] as const) {
      const v = fbo[k];
      if (typeof v !== 'string' || !v.trim()) fail(`${field}.fallback.${k}`, '必须是非空字符串');
    }
    apiOf(fbo['api'], `${field}.fallback`);
  }
```
