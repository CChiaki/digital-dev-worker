**Goal:** 交付数字员工运行时内核（pi 封装层）：EmployeeRuntime（任务包→prompt→pi Agent 循环→事件映射→resume）、CallType 模型网关（pi-ai 接管传输）、工具注册表（我们的 Tool 契约 ⇄ pi AgentTool 适配）、安全拦截层（beforeToolCall 产品化）、介入通道（steer 产品化）、任务级 session 持久化（pi JsonlSessionRepo）——模型与工具均可注入 mock，端到端可测。

**Architecture:** pnpm monorepo，包 `@ddw/runtime`。**内核 = pi-agent-core 的裸 Agent**（P0 已确认 AgentHarness 未实现、AgentSession 过度耦合，不采用）。pi-ai 的 `openai-completions` 适配器直连行内 vLLM。工具注册表只认我们的 `Tool` 接口（P2 的 MCP 工具直接复用），经适配器包装为 pi AgentTool 注入 Agent；安全拦截挂 Agent 的 `beforeToolCall`。持久化用 pi 的 `JsonlSessionRepo`（自备 Node FileSystem 适配器，从 spike 毕业），session 即 checkpoint。一切动作经 piEvent→AgentEvent 映射进 EventBus（JSONL 落盘，P3 控制台直播复用）。

**Tech Stack:** TypeScript 5.5+ / Node 20+ / pnpm workspace / vitest。运行时依赖：`@earendil-works/pi-agent-core` + `@earendil-works/pi-ai`（**锁定 0.84.4**，P0 结论：锁版本 + fork 审计准入兜底）。

## P0 实测铁律（封装层必须吸收，全部已验证）

1. `AgentTool` 必填 `label`；`execute(toolCallId, params, signal?, onUpdate?)` 返回 `{ content: [{type:'text',text}], details }`；工具内抛异常=失败（不要在 content 里编码错误）
2. Agent 构造：`new Agent({ initialState: { systemPrompt, model, tools, messages? }, streamFn, beforeToolCall? })`，Faux 测试用 `models.setProvider(faux.provider)` + `streamFn: models.streamSimple.bind(models)`
3. 落盘前必须 `JSON.parse(JSON.stringify(msg))` 规范化（`Session.appendMessage` 的 assertJsonSerializable 严格校验，拒 undefined 值/访问器/非普通对象）
4. `session.findEntries()` 返回 **newest-first**，恢复注入前必须 reverse 成时间序
5. 持久化接线必须收集 `appendMessage` 的 promise，停止时 await 全部（fire-and-forget 会产生读盘竞态）
6. 拦截层用 `beforeToolCall(ctx) => { block: true, reason }`，被拦自动产生 isError toolResult 回灌模型、循环不终止、模型可自纠偏
7. `agent.steer(AgentMessage)` 运行中入队、轮次边界注入上下文；steeringMode 支持 `"all" | "one-at-a-time"`
8. FileSystem 适配器的 Result 字段是 `ok/value/error`（`FileError(code, message, path)`），Node 无内置适配器需自建

## Global Constraints

- 完全离线运行：所有外部调用只允许指向配置传入的 baseUrl（行内私有化模型集群），禁止任何硬编码公网地址
- 模型为 OpenAI 兼容协议：glm-5.3-flash、qwen3.8-27b 按 CallType 路由，可替换（pi `Model` 对象化，切模型=换配置）
- 工具契约与实现分离：ToolRegistry 只认 `Tool` 接口，不关心背后是 API 还是 Playwright 垫片（spec 第 7.1 节）
- 全操作留痕：每次工具执行、每段模型思考都发 AgentEvent（spec 第 5.4 节）
- 测试全部离线：模型用 pi Faux Provider 脚本化，不依赖真模型；真模型仅通过配置切换接入
- 源码用 ESM（`"type": "module"`），Node 内置模块导入带 `node:` 前缀，相对导入带 `.js` 后缀
- 测试框架 vitest，每任务先写失败测试再实现（TDD）

```typescript
import { EventEmitter } from 'node:events';
import { appendFile, mkdir } from 'node:fs/promises';
import { dirname } from 'node:path';
import type { AgentEvent } from '../types.js';

export interface EventSink {
  write(event: AgentEvent): Promise<void>;
}

export class JsonlSink implements EventSink {
  constructor(private readonly filePath: string) {}

  async write(event: AgentEvent): Promise<void> {
    await mkdir(dirname(this.filePath), { recursive: true });
    await appendFile(this.filePath, JSON.stringify(event) + '\n', 'utf8');
  }
}

export class EventBus {
  private emitter = new EventEmitter();
  private sinks: EventSink[] = [];

  addSink(sink: EventSink): void {
    this.sinks.push(sink);
  }

  async emit(event: AgentEvent): Promise<void> {
    this.emitter.emit(event.type, event);
    this.emitter.emit('event', event);
    await Promise.all(this.sinks.map((s) => s.write(event)));
  }

  on(type: string, fn: (e: AgentEvent) => void): void {
    this.emitter.on(type, fn);
  }
}
```

```typescript
import type { Model, StreamFn } from '@earendil-works/pi-agent-core';
// 注：Model/StreamFn 的实际导出位置以 node_modules .d.ts 为准（pi-agent-core re-export 或 pi-ai）
import { streamSimple as openaiStreamSimple } from '@earendil-works/pi-ai/api/openai-completions';
import type { CallType, ModelSpec, RouteConfig } from '../types.js';

/** pi Model 的产品级默认值（行内模型按需覆盖） */
const DEFAULT_CONTEXT_WINDOW = 128_000;
const DEFAULT_MAX_TOKENS = 8_192;

function toPiModel(spec: ModelSpec): Model<'openai-completions'> {
  return {
    id: spec.model,
    name: spec.name,
    api: 'openai-completions',
    provider: 'ddw-custom',
    baseUrl: spec.baseUrl.replace(/\/$/, ''),
    reasoning: false,
    input: ['text'],
    cost: { input: 0, output: 0, cacheRead: 0, cacheWrite: 0 },
    contextWindow: DEFAULT_CONTEXT_WINDOW,
    maxTokens: DEFAULT_MAX_TOKENS,
    headers: { Authorization: `Bearer ${spec.apiKey}` },
  };
}

export class ModelGateway {
  private readonly routes: Map<CallType, RouteConfig>;

  constructor(routes: RouteConfig[]) {
    this.routes = new Map(routes.map((r) => [r.callType, r]));
  }

  modelFor(callType: CallType): Model<'openai-completions'> {
    const route = this.routes.get(callType);
    if (!route) throw new Error(`未配置的调用类型: ${callType}`);
    return toPiModel(route.primary);
  }

  /**
   * 返回带 fallback 的 StreamFn：primary 流式失败时，用 fallback 模型重试同一轮。
   * stream 参数可注入 fake（测试）；生产默认 openai-completions 的 streamSimple。
   */
  streamFnFor(callType: CallType, stream: StreamFn = openaiStreamSimple as StreamFn, fallbackStream?: StreamFn): StreamFn {
    const route = this.routes.get(callType);
    const fallbackSpec = route?.fallback;
    return async (model, context, options) => {
      try {
        return await stream(model, context, options);
      } catch (err) {
        if (!fallbackSpec || !fallbackStream) throw err;
        return await fallbackStream(toPiModel(fallbackSpec), context, options);
      }
    };
  }
}
```

> **实现校准点**：`Model`/`StreamFn` 若未从 pi-agent-core 导出，改从 `@earendil-works/pi-ai` 根导入（以 node_modules `.d.ts` 为准，P0 期间 pi-ai 的 `Model` 在其 `dist/types.d.ts` 定义）。`context` 参数类型为 pi 的 `Context`。

```typescript
import type { AgentTool } from '@earendil-works/pi-agent-core';
import type { Tool, ToolParamSpec } from '../types.js';

/** ToolParamSpec（产品契约）→ JSON Schema（pi 透传给 provider，P0-S6 已验证兼容） */
function toJsonSchema(params: ToolParamSpec): {
  type: 'object';
  properties: Record<string, { type: string; description: string }>;
  required: string[];
} {
  const properties: Record<string, { type: string; description: string }> = {};
  const required: string[] = [];
  for (const [key, spec] of Object.entries(params)) {
    properties[key] = { type: spec.type, description: spec.description };
    if (spec.required) required.push(key);
  }
  return { type: 'object', properties, required };
}

/** 我们的 Tool 契约 → pi AgentTool。
 *  - label 必填（P0 铁律 1）
 *  - ok:false 抛异常 → pi 标 isError toolResult 回灌模型（不要在 content 里编码错误）
 */
export function toPiTool(tool: Tool): AgentTool {
  return {
    name: tool.name,
    label: tool.name,
    description: tool.description,
    parameters: toJsonSchema(tool.parameters),
    execute: async (_toolCallId, params) => {
      const result = await tool.execute(params as Record<string, unknown>);
      if (!result.ok) {
        throw new Error(result.error ?? `工具 ${tool.name} 执行失败`);
      }
      return {
        content: [{ type: 'text', text: JSON.stringify(result) }],
        details: result,
      };
    },
  };
}
```

```typescript
import type { BeforeToolCall } from '@earendil-works/pi-agent-core';
import type { ToolInterceptor } from './types.js';
// 注：若 pi-agent-core 未导出 BeforeToolCall 类型，用 P0-S2 实测签名内联：
// (ctx: { toolCall: { name: string }, args: Record<string, unknown> }) => Promise<{ block: true; reason: string } | undefined>

export type { ToolInterceptor, InterceptorVerdict } from './types.js';

/** 拦截器链 → pi beforeToolCall。首个 block 生效；全放行返回 undefined。 */
export function makeBeforeToolCall(interceptors: ToolInterceptor[]): BeforeToolCall {
  return async (ctx) => {
    for (const icpt of interceptors) {
      const verdict = icpt.check({ toolName: ctx.toolCall.name, args: ctx.args ?? {} });
      if (verdict) {
        return { block: true, reason: `[${icpt.name}] ${verdict.reason}` };
      }
    }
    return undefined;
  };
}
```

```typescript
import type { ToolInterceptor } from './types.js';

/** S2 毕业的黑名单。P1 版本=模式清单；P4 容器化后升级为"白名单+最小 shell"。 */
const BLOCKED: { name: string; re: RegExp }[] = [
  { name: '递归强删', re: /\brm\s+(-[a-z]*r[a-z]*f|-[a-z]*f[a-z]*r)\b/ },
  { name: '根/设备写入', re: /\brm\s+-[a-zA-Z]*\s+\/(\s|$)/ },
  { name: '关机重启', re: /\b(shutdown|reboot|halt|poweroff)\b/ },
  { name: '格式化文件系统', re: /\bmkfs\b/ },
  { name: '磁盘镜像写入', re: /\bdd\s+if=/ },
  { name: 'fork炸弹', re: /:\(\)\s*\{\s*:\|:&\s*\};:/ },
  { name: '公网外呼', re: /\b(curl|wget)\b[^|]*\bhttps?:\/\/(?!(10\.|172\.(1[6-9]|2\d|3[01])\.|192\.168\.|127\.|localhost))/ },
  { name: '权限提升', re: /\b(sudo|su)\s/ },
  { name: '计划任务持久化', re: /\bcrontab\b/ },
];

export class BashBlacklist implements ToolInterceptor {
  name = 'bash-blacklist';

  check(input: { toolName: string; args: Record<string, unknown> }): { block: boolean; reason: string } | null {
    if (input.toolName !== 'bash' && input.toolName !== 'run_cmd') return null;
    const cmd = String(input.args['cmd'] ?? input.args['command'] ?? '');
    if (!cmd) return null;
    for (const p of BLOCKED) {
      if (p.re.test(cmd)) {
        return { block: true, reason: `run_cmd 被安全策略拦截（${p.name}）：请改用安全方式完成任务` };
      }
    }
    return null;
  }
}
```

```typescript
import { join } from 'node:path';
import { JsonlSessionRepo, type Session, type AgentMessage } from '@earendil-works/pi-agent-core';
import { makeNodeFs } from '../fs/node-fs.js';

/** 任务级 session 存储：taskId ↔ pi session 一对一（session 即 checkpoint，消息级实时落盘）。 */
export class EmployeeSessionStore {
  private repo: JsonlSessionRepo;

  constructor(private readonly root: string) {
    this.repo = new JsonlSessionRepo({
      fs: makeNodeFs(root),
      sessionsRoot: join(root, 'sessions'),
    });
  }

  /** 幂等：同 taskId 首次 create、后续 open 同一 session。 */
  async open(taskId: string): Promise<Session> {
    const taskDir = join(this.root, 'tasks', taskId);
    const existing = (await this.repo.list()).find(
      (m) => (m as { cwd?: string }).cwd === taskDir,
    );
    return existing ? this.repo.open(existing) : this.repo.create({ cwd: taskDir });
  }
}

/** 读回消息（时间序）。P0 铁律 4：findEntries 是 newest-first，必须 reverse。 */
export async function loadMessages(session: Session): Promise<AgentMessage[]> {
  const entries = await session.findEntries();
  return entries
    .filter((e) => e.type === 'message')
    .map((e) => (e as { message: AgentMessage }).message)
    .reverse();
}
```

```typescript
import { randomUUID } from 'node:crypto';
import type { AgentEvent } from '../types.js';

/** pi 事件 → AgentEvent（P0-S3 实测映射）。返回 null 的事件不进直播流。 */
export function piEventToAgentEvent(piEvent: any, taskId: string, employeeId: string): AgentEvent | null {
  switch (piEvent.type) {
    case 'message_end':
      if (piEvent.message?.role === 'assistant') {
        const text = (piEvent.message.content ?? [])
          .filter((c: any) => c.type === 'text')
          .map((c: any) => c.text)
          .join('');
        if (text) {
          return {
            id: randomUUID(), ts: Date.now(), taskId, employeeId,
            type: 'thinking', summary: text.slice(0, 200), payload: { content: text },
          };
        }
      }
      return null;
    case 'tool_execution_end':
      return {
        id: randomUUID(), ts: Date.now(), taskId, employeeId,
        type: 'tool_call',
        summary: piEvent.toolName,
        payload: { toolCallId: piEvent.toolCallId, result: piEvent.result, isError: piEvent.isError },
      };
    default:
      return null;
  }
}
```

`packages/runtime/src/runtime/employee-runtime.ts`：

```typescript
import { randomUUID } from 'node:crypto';
import {
  Agent,
  type AgentMessage,
  type AgentTool,
  type BeforeToolCall,
  type StreamFn,
} from '@earendil-works/pi-agent-core';
import type { AgentEvent, CallType, EventBus, ToolRegistry } from '../types.js';
import type { ModelGateway } from '../model/gateway.js';
import { toPiTool } from '../tools/pi-adapter.js';
import { makeBeforeToolCall } from '../security/interceptor.js';
import type { ToolInterceptor } from '../security/types.js';
import type { EmployeeSessionStore } from '../session/employee-session.js';
import { wireSession } from '../session/wire.js';
import { piEventToAgentEvent } from './event-map.js';

export interface EmployeeRuntimeConfig {
  employeeId: string;
  maxTurns?: number; // 默认 40
}

export interface TaskInput {
  taskId: string;
  instruction: string;
}

export type EmployeeOutcome =
  | { status: 'done' | 'max_turns'; reply: string; turns: number };

export interface AgentDeps {
  createAgent(opts: {
    model: unknown;
    streamFn: StreamFn;
    tools: AgentTool[];
    beforeToolCall?: BeforeToolCall;
    messages?: AgentMessage[];
  }): Agent;
}

export class EmployeeRuntime {
  private readonly active = new Map<string, Agent>();
  private readonly turns = new Map<string, number>();
  private readonly maxTurns: number;
  private readonly callType: CallType;

  constructor(
    private readonly deps: {
      gateway: ModelGateway;
      tools: ToolRegistry;
      interceptors: ToolInterceptor[];
      events: EventBus;
      sessions: EmployeeSessionStore;
      config: EmployeeRuntimeConfig;
      callType?: CallType;
      agentFactory?: AgentDeps['createAgent']; // 测试注入点；生产默认 createPiAgent
    },
  ) {
    this.maxTurns = deps.config.maxTurns ?? 40;
    this.callType = deps.callType ?? 'code';
  }

  private async emit(taskId: string, partial: Omit<AgentEvent, 'id' | 'ts' | 'taskId' | 'employeeId'>): Promise<void> {
    await this.deps.events.emit({
      id: randomUUID(), ts: Date.now(), taskId,
      employeeId: this.deps.config.employeeId, ...partial,
    });
  }

  private makeAgent(taskId: string, messages?: AgentMessage[]): Agent {
    const create = this.deps.agentFactory ?? createPiAgent;
    const agent = create({
      model: this.deps.gateway.modelFor(this.callType),
      streamFn: this.deps.gateway.streamFnFor(this.callType),
      tools: this.deps.tools.list().map((t) => toPiTool(this.deps.tools.get(t.name)!)),
      beforeToolCall: makeBeforeToolCall(this.deps.interceptors),
      ...(messages ? { messages } : {}),
    });

    // 事件映射 + 轮次计数
    agent.subscribe((e: any) => {
      if (e.type === 'turn_end') {
        this.turns.set(taskId, (this.turns.get(taskId) ?? 0) + 1);
      }
      const mapped = piEventToAgentEvent(e, taskId, this.deps.config.employeeId);
      if (mapped) void this.deps.events.emit(mapped);
    });
    return agent;
  }

  async run(task: TaskInput): Promise<EmployeeOutcome> {
    const agent = this.makeAgent(task.taskId);
    const session = await this.deps.sessions.open(task.taskId);
    const stop = wireSession(agent, session);
    this.active.set(task.taskId, agent);
    try {
      await agent.prompt(task.instruction);
    } catch (err) {
      await this.emit(task.taskId, {
        type: 'error',
        summary: `任务执行失败: ${err instanceof Error ? err.message : String(err)}`,
      });
      throw err;
    } finally {
      await stop();
      this.active.delete(task.taskId);
    }
    return this.collect(task.taskId, agent);
  }

  async resume(taskId: string): Promise<EmployeeOutcome> {
    const session = await this.deps.sessions.open(taskId);
    const messages = await (await import('../session/employee-session.js')).loadMessages(session);
    const agent = this.makeAgent(taskId, messages);
    const stop = wireSession(agent, session);
    try {
      await agent.prompt('继续完成任务并汇报结果');
    } finally {
      await stop();
    }
    return this.collect(taskId, agent);
  }

  /** S7 介入通道：运行中注入消息 + 审计留痕。返回 false=任务不在运行中。 */
  steer(taskId: string, message: string): boolean {
    const agent = this.active.get(taskId);
    if (!agent) return false;
    agent.steer({
      role: 'user',
      content: [{ type: 'text', text: message }],
      timestamp: Date.now(),
    } as AgentMessage);
    void this.emit(taskId, { type: 'intervention', summary: message.slice(0, 200) });
    return true;
  }

  private collect(taskId: string, agent: Agent): EmployeeOutcome {
    const msgs = agent.state.messages;
    const last = msgs.at(-1);
    const reply =
      last?.role === 'assistant'
        ? (last.content as { type: string; text?: string }[])
            .filter((c) => c.type === 'text')
            .map((c) => c.text ?? '')
            .join('')
        : '';
    const turns = this.turns.get(taskId) ?? 0;
    return { status: turns >= this.maxTurns ? 'max_turns' : 'done', reply, turns };
  }
}

/** 生产 Agent 工厂（pi 直连） */
function createPiAgent(opts: {
  model: unknown;
  streamFn: StreamFn;
  tools: AgentTool[];
  beforeToolCall?: BeforeToolCall;
  messages?: AgentMessage[];
}): Agent {
  return new Agent({
    initialState: {
      systemPrompt: '',
      model: opts.model as never,
      tools: opts.tools,
      ...(opts.messages ? { messages: opts.messages } : {}),
    },
    streamFn: opts.streamFn,
    ...(opts.beforeToolCall ? { beforeToolCall: opts.beforeToolCall } : {}),
  });
}
```
