# 管理端样式重构 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 管理台（apps/console）样式用 Tailwind v4 全量重写并落视觉 UI 标准，任务中心改传统检索区+表格布局，创建表单下拉化，draft 文案改「待发布」。

**Architecture:** Tailwind v4（@tailwindcss/vite，CSS-first）+ Element Plus 混合——Tailwind 管布局/间距/卡片/排版/状态色，EP 管交互控件；design token 落 `src/style.css` 的 `@theme` 并映射回 EP CSS 变量保证同色。纯前端改造，后端零改动。

**Tech Stack:** Tailwind CSS v4、@tailwindcss/vite、Vue 3、Element Plus 2.14、vitest（jsdom）、vue-tsc。

## Global Constraints

- spec：`docs/superpowers/specs/2026-09-06-管理端样式重构-design.md`（逐字约束来源）。
- 分工约定：Tailwind 管布局/间距/卡片/排版/状态色；EP 管交互控件；仅 `:deep()` 覆写 EP 内部结构时保留 scoped style（各文件 ≤10 行）。
- 布局标准：brand 区高 **70px**；header 高 **56px**；内容区限宽 1280px；间距一律 4 的倍数；卡片统一 `rounded-xl border shadow-sm hover:shadow-md`。
- 主色 #2f6bff 沿用；token 单一事实源在 `@theme`，`:root` 映射回 EP 变量。
- 状态文案：`draft` 显示 **「待发布」**；`pending=warning(橙) / claimed=primary(蓝) / running=primary(蓝) / done=success(绿) / failed=danger(红) / draft=info(灰)` 色表统一放 `src/status.ts`。
- 发布成功 toast 文案：`'已发布，任务进入待分派'`。
- 编排视图：TaskCenter 移除切换与挂载；`TaskDag.vue` 保留文件，顶部加注释 `// TODO(编排视图缓发 2026-09-06)：全任务依赖编排视图，后续迭代恢复入口`。
- 后端零改动；纯前端（apps/console）。不引入暗色模式、不做移动端适配。
- 测试基线：console `18 files / 108 用例`，`vue-tsc --noEmit` 零错误——每个任务收尾必须维持全绿。
- 测试不监听端口；禁止启动服务/打包（vite dev 不跑）；依赖安装（pnpm add -D）允许。
- 简报与真实代码有偏差时：以真实代码为准适配 + 报告申报偏差；测试以真实通过为准。
- 提交：中文 conventional commit（`feat(console): ...`），末尾加 `Co-Authored-By: Claude Code <noreply@anthropic.com>`。

```ts
  const kwOk = !kw.trim() || t.taskId.includes(kw.trim()) || t.title.includes(kw.trim());
  const stOk = statuses.length === 0 || statuses.includes(t.status);
  return kwOk && stOk;
}
const visibleTasks = computed(() => tasks.value.filter((t) => matches(t, keyword.value, statusFilter.value)));
defineExpose({ matches });
```
