# 任务指定员工分派（assignee）Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 发布任务可指定数字员工执行——点名分派、忽略岗位、忙等自动排队、员工不可用留池等人工。

**Architecture:** runtime 任务包新增 `assignee` 可选字段（白名单校验）→ `ManagedRoster` 新增 `acquireById`/`isKnown` → 调度器 tick 点名分派（留痕区分忙/不可用）→ 前端表单下拉 + yaml 序列化 + 详情展示。排队语义免费获得：员工独占 + pending 池 tick 重试是现有机制。

**Tech Stack:** packages/runtime（task schema）、packages/console-api（scheduler/roster）、apps/console（Vue3 + EP + Tailwind v4）。

## Global Constraints

- 字段名 `assignee`（员工 id，可选；与 role 可共存，运行时 assignee 优先忽略 role）。
- `parseTaskPackage` 是白名单拼装——接口、校验、return 拼装三处必须同步，否则字段静默丢弃。
- 指定员工不存在/停用 → 任务留池，留痕文案 `waiting: 指定员工不可用（{id}），等人工处理`；正忙 → `waiting: 指定员工 {id} 正忙，完成后自动分派`。发布时不校验员工状态。
- dependsOn readiness 判定不变（先过依赖关再点名）。
- 前端：下拉排除停用员工；员工列表拉取失败不阻塞表单；`assignee` 不进 `LEGACY_FIELDS`。
- 测试不监听端口；命令：`pnpm --filter @ddw/runtime exec vitest run`、`pnpm --filter console-api exec vitest run`、`pnpm --filter console exec vitest run`、各包 typecheck。
- 提交：中文 conventional commits，末尾 `Co-Authored-By: Claude Code <noreply@anthropic.com>`。

managed-roster.ts 接口与方法：

```ts
export type SchedulerRoster = {
  acquire(role?: string, extra?: (p: EmployeeProfile) => boolean): EmployeeProfile | null;
  /** 点名分派（2026-09-06 assignee）：空闲且启用时占用返回；忙/不存在/停用 → null */
  acquireById(id: string): EmployeeProfile | null;
  /** 员工存在且启用（不含占用状态）；与 acquireById 同快照，供调度留痕区分「忙」与「不可用」 */
  isKnown(id: string): boolean;
  release(id: string): void;
};
```

```ts
  private profileOf(r: EmployeeRecord): EmployeeProfile {
    return {
      id: r.id, name: r.name, role: r.role, skills: [...r.skills],
      ...(r.supervision ? { supervision: r.supervision } : {}),
    };
  }

  acquireById(id: string): EmployeeProfile | null {
    const hit = this.records.find((r) => r.id === id && this.free.has(r.id));
    if (!hit) return null;
    this.free.delete(hit.id);
    return this.profileOf(hit);
  }

  isKnown(id: string): boolean {
    return this.records.some((r) => r.id === id);
  }
```

（顺手把 acquire 内两处重复的 profile 字面量替换为 `profileOf`，行为不变。）

      // 分派（2026-09-06 assignee）：指定员工 → 点名（忽略 role 匹配）；未指定 → 按岗位挑空闲
      const assignee = rec.pkg.assignee;
      const employee = assignee
        ? this.deps.roster.acquireById(assignee)
        : this.deps.roster.acquire(
            rec.pkg.role,
            this.deps.canDispatch ? (p) => this.deps.canDispatch!(rec, p) : undefined,

      if (!employee) {
        this.note(
          taskId,

            : 'waiting: 无空闲员工匹配岗位',

        );
