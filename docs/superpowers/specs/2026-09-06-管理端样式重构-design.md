# 管理端样式重构设计（Tailwind v4 重写 + 视觉 UI 标准 + 任务中心表格化）

日期：2026-09-06 ｜ 状态：已与用户对齐，待评审

## 背景与需求

管理台重构（P16 补充 6）落地后为 Element Plus 默认样式 + 各组件零散 scoped style，用户提出：
样式用 Tailwind CSS 重新写、视觉 UI 标准落地成文，并修复若干体验问题。与用户确认的决策：

| 决策点 | 结论 |
|---|---|
| 样式架构 | **Tailwind v4 + Element Plus 混合**：Tailwind 管布局/间距/卡片/排版/状态色，EP 管交互控件（表格/表单/对话框/开关/弹窗） |
| 改造范围 | **全量迁移**：13 个 view + 5 个组件的 scoped style 迁为 Tailwind 工具类 |
| 首页风格 | **简洁数据卡**：白卡+彩色图标块+大数字；员工区浅灰背景分区 + 首字母徽章员工卡 |
| 布局尺寸 | brand 区高 **70px**，header 高 **56px**，内容区限宽 1280px 不变 |
| 任务中心 | 传统上下布局：上检索功能区 + 下 el-table；**编排视图移除**（TaskDag 封存打标，后续迭代） |
| 创建表单下拉 | **岗位 role** 下拉（选项=员工档案 skills，filterable+allow-create）；**依赖 dependsOn** 多选下拉（选项=已有任务） |
| 草稿文案 | draft 状态显示 **「待发布」**（现状「草稿」；用户报告的「已发布」实为发布成功 toast，一并改文案消歧） |

## 设计

### 1. 技术底座（Tailwind v4 接入）

- 依赖：`pnpm add -D tailwindcss @tailwindcss/vite`（仅 apps/console，devDependencies）；
  `vite.config.ts` 挂 `tailwindcss()` 插件；`src/main.ts` 引入 `import 'tailwindcss'`（v4 CSS-first，无 config 文件）；
- **Design token（视觉 UI 标准）落 `src/style.css`**（新建，替代 App.vue 全局 style 块）：
  - `@theme` 定义：品牌色阶 `--color-brand-50..900`（主色 #2f6bff 沿用）、语义色
    `--color-success/-warning/-danger`、字号刻度、圆角（卡片 `rounded-xl`）、阴影（`shadow-sm`/`shadow-md`）；
  - 同文件 `:root` 把 token 映射回 Element Plus 变量（`--el-color-primary: var(--color-brand-600)` 等）——
    **EP 组件与 Tailwind 类永远同色**，单一事实源在 @theme；
  - body 字体/背景、`.muted`、页头竖条等公共样式迁入（utility 为主，个别复杂选择器留 CSS）；
- 分工约定（写入 spec 作为审查标准）：Tailwind 管布局/间距/卡片/排版/状态色；EP 管交互控件；
  仅 `:deep()` 覆写 EP 内部结构时保留少量 scoped style（各文件 ≤10 行）。

### 2. 布局规范（UI 标准）

- **brand 区高 70px**：logo 36px 渐变方块 + 「数字AI研发人员 / DIGITAL AI ENGINEER」双行，垂直居中；
- **header 56px**（现状已 56，固化进 token 注释）：深色吸顶，左标题右 MessageBell；
- 侧边栏藏青渐变保留（Tailwind arbitrary value 或 @theme 自定义色）；
- 内容区限宽 1280px 居中不变；页头统一「主色竖条 + 标题 + 右侧操作区」；
- 间距一律 4 的倍数（Tailwind p-2/4/6…）；卡片统一 `rounded-xl border border-gray-200 shadow-sm hover:shadow-md`。

### 3. 首页面板（简洁数据卡）

- **统计四卡**：白卡 + 左侧彩色图标块（进行中=蓝/已完成=绿/失败=红/待放行=橙）+ 28px 大数字 + 灰字说明；
  失败卡红主题、hover 提升、点击跳 `/tasks` 并自动预选状态筛选「失败」（衔接 §4 检索区）；
- **视觉分区**：统计区白底；下方「数字员工」section 标题条 + `bg-gray-50` 浅灰背景区块，两层一眼区分；
- **员工卡重绘**：
  - 首字母徽章（姓名首字）：忙=主色底、闲=绿底、停用=灰底（停用整卡灰显不变）；
  - 忙闲状态色点 + 文案；岗位·盯梢期一行；能力彩色小徽标（空=「全部能力」）；
  - 底部「完成 N 单 ›」行；hover 上浮；点击下钻 `/employees/:id` 不变；
- 数据来源与 5s 轮询逻辑零改动（纯样式层重构）。

### 4. 任务中心：传统上下布局

- **上检索功能区**：
  - 关键词输入框（匹配 taskId / 标题，前端过滤）；
  - 状态多选下拉（待发布/待分派/已接单/执行中/已完成/失败，空=全部）；
  - 右侧「新建任务」主按钮；错误 alert 保留；
- **下 el-table**：任务ID / 标题 / 状态 tag / 领取人 / 岗位 / 依赖 / 计划进度 / 操作列
  （「详情」恒有；draft 行加「发布」；claimed/running 行加「直播」）；行点击进 `/tasks/:id`；
- **编排视图移除**：页内「列表/编排」切换按钮删除，TaskDag 挂载解除；
  `src/components/TaskDag.vue` 文件保留 + 顶部打注释
  `// TODO(编排视图缓发 2026-09-06)：全任务依赖编排视图，后续迭代恢复入口`；
- 轮询逻辑零改动。

### 5. 创建对话框下拉化

- **岗位 role**：`el-select filterable allow-create`（可手输新岗位），选项 = 员工档案 skills 去重
  （对话框打开时拉一次 `GET /api/employees`）；空选项保留（缺省不限岗位）；
- **依赖 dependsOn**：`el-select multiple`，选项 = 已有任务（taskId + 标题，排除自身）；
  form 模式新增该字段（现表单模式无 dependsOn 入口），提交进 yaml；
- 计划项 kind 下拉已有（选项=已启用能力）不动；表单/yaml/AI 三模式结构保留；
- 交互细节：下拉选项加载失败不阻塞对话框（选项为空仍可手输 role / 不选依赖）。

### 6. 状态文案与映射统一

- `src/status.ts`：`draft: '草稿'` → `draft: '待发布'`（TASK_STATUS_ZH 单点全局生效）；
- 「发布」成功 toast：`'已发布'` → `'已发布，任务进入待分派'`（消歧：发布动作成功 ≠ 状态显示）；
- **STATUS_TAG 色表抽到 status.ts** 统一维护（现 4 处组件各自复制）：
  `draft=info(灰) / pending=warning(橙) / claimed=primary(蓝) / running=primary(蓝) / done=success(绿) / failed=danger(红)`；
  各组件（TaskCenter/TaskDag/TaskDetail/EmployeeDetail）改为引用，EmployeeDetail 缺 draft/pending 键的
  覆盖缺口一并修复；
- 后端 TaskStatus 枚举与 API 零改动（纯展示层）。

### 7. 错误处理

| 场景 | 处理 |
|---|---|
| 员工列表/任务列表拉取失败（下拉选项来源） | 选项为空不阻塞对话框，role 可手输、依赖可不选 |
| 关键词过滤无匹配 | 表格空态文案「无匹配任务」+ 一键清筛选 |
| 发布按钮在他人已发布后点击 | 409 可读文案（后端已有，前端透出即可） |

### 8. 测试

- **回归**：现有 108 用例行为断言（渲染文本/API 调用参数）基本不动；class 名相关断言随迁移更新；
- **新增**：
  - 任务中心：关键词/状态过滤逻辑、el-table 渲染行数与操作列按钮条件（draft→发布、claimed/running→直播）；
  - 创建对话框：role 选项来源（skills 去重）、dependsOn 选项（排除自身）、提交 yaml 含所选依赖；
  - status.ts：draft→「待发布」、STATUS_TAG 统一色表；
  - TaskCenter 无编排入口（TaskDag 不再被挂载）；
- **验收**：`vitest run` + `vue-tsc --noEmit` 全绿；浏览器人工过一遍六节视觉清单。

### 9. 兼容与迁移

- 纯前端改造（apps/console），后端零改动；
- `App.vue` 全局 style 块迁入 `src/style.css`，组件 scoped style 迁 Tailwind utilities（`:deep()` 残留除外）；
- 测试 mount-helper/plugins 结构不动。

## 不做的事（YAGNI）

- 不做暗色模式；
- 不重写 EP 内部结构（表格/表单控件继续用 EP）；
- 不物理删除 TaskDag.vue（封存打标）；
- 不做响应式移动端适配（管理台桌面场景）；
- 不改后端任何接口与状态枚举。
