# 管理台体验修复与风格统一设计（返回导航 / 列表页风格 / size 默认 / 消息中心 400）

日期：2026-09-06 ｜ 状态：已与用户对齐，待实施

## 背景与需求

管理端样式重构（P16 补充 7）落地后用户提出四点：
①下钻详情页无法返回上一页；②列表页风格不统一（有的是任务中心风格、有的是其他），
要求全部统一为任务中心风格（上检索/功能按钮 + 下表格）；③Element Plus 组件 size
一律用默认值（现状除任务中心外全站 small）；④控制台报 `GET /api/messages 400`。

## 排查结论（2026-09-06 探查）

| 问题 | 根因 |
|---|---|
| 无法返回 | TaskDetail / EmployeeDetail / EmployeeLive 三个详情页均无返回 UI（全 src 无 router.back/page-header） |
| 风格不齐 | 除 TaskCenter（default）外所有页面组件 `size="small"`（el-table/el-tag/el-button/el-select/el-radio-group/el-descriptions ~30 处）；CheckReview 为卡片流非表格 |
| /api/messages 400 | `server.ts` 创建了 FileMessageStore 但调 `createHandlers({...})` 时**漏传 `messages` 依赖** → handlers 命中「未启用消息中心」400。非前端参数问题 |

## 设计

### 1. 返回导航

- 三个详情页页头（`.view > h2` 行）左侧统一加「← 返回」按钮：`el-button :icon="ArrowLeft" text` + `@click="router.back()"`；
- EmployeeLive 页头现有员工切换 tab 保留，返回按钮置于标题左。

### 2. 列表页风格统一（标杆 = TaskCenter）

统一标准：**顶部一行工具条（左：检索/筛选；右：主操作按钮）+ 下 el-table**，间距对齐任务中心（工具条 mb-4、按钮 ml-auto）。

| 页面 | 动作 |
|---|---|
| Employees | 加姓名/岗位关键词检索框（前端过滤），与表格 size 归默认 |
| AuditLog | 保留类型筛选（radio→保留交互），结构对齐标杆 |
| Capabilities | 头部按钮对齐右置；加关键词筛选（kind/描述） |
| Channels | 头部按钮对齐右置；加关键词筛选（名称） |
| CheckReview | **卡片流 → 检索区 + el-table**：列 = 任务/员工/检查项/盯梢级/状态/提交时间/操作（行内「通过」「驳回」，驳回弹输入框——沿用现有驳回逻辑）；检索区 = 状态筛选 + 任务关键词 |
| TaskCenter | 标杆不动（仅核查一致性） |
| Dashboard | 首页卡片流保留（不在列表页统一范围） |

### 3. size 全站归默认

- 删除全部组件 `size="small"` / `:size` 小值属性（~30 处，grep 核验清零）；
- el-drawer `size="400px"` 为宽度属性，**保留**；
- TaskCreateDialog `el-form size="default"` 显式值删除（等价缺省）；
- 不引入全局 ElConfigProvider（YAGNI，删除即默认）。

### 4. 消息中心 400 修复

- `packages/console-api/src/http/server.ts` 的 `createHandlers({...})` 补传 `messages`（FileMessageStore 实例已存在）；
- 后端测试补 1 条：GET /api/messages 返回 200 且结构正确（防回归）。

### 5. 死代码清理

- 删除 `src/views/EmployeeRoster.vue`（未注册路由、无引用）及其测试（如有）。

## 测试

- 消息中心：后端 GET /api/messages 200 防回归用例；前端 MessageBell 拉取成功渲染（既有用例随修复恢复真实链路）；
- CheckReview：表格渲染、状态筛选、行内通过/驳回（驳回走输入框路径）用例；
- Employees 检索过滤用例；
- size 清零后既有断言中的 small 钩子同步；
- 返回按钮：点击触发 router.back（mock 断言）×3 页；
- 回归：四包 vitest + vue-tsc 全绿。

## 不做的事（YAGNI）

- 不改路由结构、不加面包屑；
- 不做全局 ElConfigProvider；
- 不动 Dashboard 首页卡片流；
- 不做 el-pagination 分页（当前数据量不需要）。
